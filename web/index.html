JIM isn't running on this computer

This page is the interface. JIM's brain runs on your PC so it can open apps, listen and stay private.

  1. Install Python 3.10+
  2. Download JIM: git clone https://github.com/Amaljith75/jim
    or download ZIP
  3. Start it: double-click scripts/start-windows.bat (Mac/Linux: ./scripts/start-mac-linux.sh)
  4. Come back here and press Connect. If Chrome asks to allow access to devices on your local network, allow it.

JIM combines every enabled model that has a key. Free keys: Groq, Gemini, Cerebras, OpenRouter, Mistral. Ollama runs offline on your PC with no key. You can add any service with an OpenAI-compatible API.
